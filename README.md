# DomifyTool

App móvil (Android + iOS) del taller automotriz, contra la API de
`tool_core_backend`.

## Requisitos

- Flutter con Dart SDK `^3.13.0`
- Android Studio / Xcode para los emuladores

## Arranque

```bash
flutter pub get
flutter run
```

## Comprobaciones

```bash
flutter analyze
flutter test
```

Las decisiones de cada fase se registran en `docs/notas/`.
